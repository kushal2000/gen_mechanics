2. _compose_bend_rpy adds Euler components: exact today only because projection sets phalanx-0 bend to 0; if a grammar mutates phalanx-0 bend, the effective rotation axis is off by median 4.7 deg, up to 90 deg; 3/65 real mounts are near gimbal lock. Representation-level; fix to R(mount) R(bend) (byte-identical when bend == 0) or ban phalanx-0 bend.
3. Gauge: projection is deterministic but not unique (URDF axis sign, root origin, root roll, point along axis) and discontinuous for axes parallel to the link and zero-length links. Recommend a parallel-transport (minimal-twist) gauge: child x = parent x carried by the minimal rotation from parent z to child z; zero-length bodies inherit the parent frame. Then bend_rpy is a pure swing (the physical bend) and twist lives in the axes.
